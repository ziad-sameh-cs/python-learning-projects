# python-learning-projects

Learning projects from my Python Programming Basics course — small practice projects in data analysis, charts, and data structures. These are learning projects, not client work.

## Projects

- `pandas_data_analysis.py` — Pandas data analysis: builds a small sample dataset and summarises it with `describe()` and `groupby()`.
- `matplotlib_chart.py` — Matplotlib chart: draws a bar chart of weekly study hours and saves it as `study_hours.png`.
- `data_structures_practice.py` — Data-structures practice: lists, dictionaries, sets, and a simple stack.

## How to run

```bash
python pandas_data_analysis.py
python matplotlib_chart.py
python data_structures_practice.py
```
